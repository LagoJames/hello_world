# Hello World Repository

A collection of "Hello World" examples in various programming languages to help beginners learn the basics of programming.

## About

This repository contains simple "Hello World" programs in different programming languages. "Hello World" is traditionally the first program written when learning a new programming language, making it a perfect starting point for beginners.

## Examples Included

- **Python**: A simple Hello World script in Python
- **JavaScript**: A Hello World program in JavaScript
- **C**: A classic Hello World in C
- **Java**: A Hello World example in Java
- **HTML**: A Hello World web page

## How to Run

### Python
```bash
python hello_world.py
```

### JavaScript
```bash
node hello_world.js
```

### C
```bash
gcc hello_world.c -o hello_world
./hello_world
```

### Java
```bash
javac HelloWorld.java
java HelloWorld
```

### HTML
Simply open the `hello_world.html` file in any web browser.
